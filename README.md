# 💰 Expense Tracker

A simple Expense Tracker web application built using Streamlit, Pandas, Matplotlib, and Seaborn.

## Features

- Add daily expenses
- Categorize expenses
- View all expense records
- Upload expenses from a CSV file
- Download expenses as a CSV file
- Visualize expenses by category using charts
- View total spending

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/expense-tracker.git
```

2. Navigate to the project folder

```bash
cd expense-tracker
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
streamlit run app.py
```

## How to Use

1. Enter expense details from the sidebar.
2. Choose a date, category, amount, and description.
3. Click **Add Expense** to save the record.
4. View all expenses in the table.
5. Download expenses as a CSV file.
6. Upload a CSV file to load previous expenses.
7. Click **Generate Visualization** to see category-wise spending.
